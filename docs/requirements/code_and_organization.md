Code and organization requirements

1. The code must be written in python
2. The code must be written following pep 8 style guide
3. The code must be written in the design patterns called MVC - model, view, controller
4. The project must be kept in a folder that contains the sub-folder: src, test, bin.
5. The src folder must contain all the code  and other artifacts need to run the code
6. The test folder must contain all the tests used to evaluate the code
7. The bin folder must contain all the binary files created when the code is compiled to run
8. The srs folder must contain the following sub-folders: model, view, controller
9. The view code must be kept separate from the model and controller code.
10. The code comments, besides explaining the code, must trace each code section to at least one low level functional requirement.
11. A new external library must only be added when there is high confidence that the current set of library is not enough. 
12. The name of the variables, classes, methods must be meaningful /self explanatory. Avoid using unnecessary abbreviations.
13. The size name of the variables must be lower than 40 characters.
14. The name of the variables must use suffixes that point the type of variables:  dict for dictionaries, f for float, i for integers, b for boolean.
15. If the variables carries information about a physical quantity, the f for float on the suffix must be replace by suffix that is the abbreviation for the physical quantity as recommend by the international measurement system.
16. All the code must be written in English.
17. All the classes and function must have an explanation of the inputs, outputs and what it does.
18. The code must follow the zen of python guidelines.
