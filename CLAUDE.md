## How to work in this repository

- Before any work, make sure a GitHub issue exists for it (PCR-00012). Create it from the Fix or Feature template in `.github/ISSUE_TEMPLATE/`. When creating it with `gh`, use the same sections as the template.
- Create the branch from `develop` and name it `feature/<issue number>-<short-name>` or `fix/<issue number>-<short-name>` (PCR-00003, PCR-00005).
- Open pull requests into `develop`. Never merge into `main`: that needs human approval (PCR-00015).
- Do not merge your own work. A different agent or a human must review and test it first (PCR-00016).
- Before a pull request is merged, fill in the remaining sections of its issue (PCR-00014).
- Work in your own git worktree (PCR-00026).
